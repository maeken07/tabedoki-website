# たべどき！！ 公式紹介サイト

食材の期限・在庫管理アプリ「たべどき！！」の紹介サイトです。

公開URL: https://maeken07.github.io/tabedoki-website/

iPhoneアプリは公開準備中です。Webサイトのデータの取り扱いと、配信前の正式なアプリ用ポリシーは区別しています。

このリポジトリは、確認した静的な公開ファイルを保存します。アプリ本体の開発元: https://github.com/arukuArupaka/Torikawa

## 更新

開発元の website/ と関係する原稿を更新し、テスト・型チェックのあとに npm run site:build -- --announcement で生成したファイルを配置します。未確定のアプリ用ポリシー、ローカル設定、在庫、問い合わせの回答は配置しません。

アプリを正式配信するときは、開発元で正式ポリシーを完成させ、通常の site:build で出力したものへ更新します。現在のWebサイト向けの案内を、正式なアプリ用ポリシーとして登録しません。
